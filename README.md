# Coffee Point

Лендинг кофейни с серверной частью (Node.js + Express) и ИИ-чат-ботом на OpenAI.

```
├── server/
│   ├── index.js      # Express: раздача статики + POST /api/chat
│   └── context.js    # База знаний бота (меню, цены, контакты, правила)
├── public/
│   ├── index.html    # Разметка + виджет чата
│   ├── style.css     # Стили, в том числе виджета
│   ├── script.js     # прежнее поведение лендинга
│   └── chat.js       # Клиент чата: история, отправка, ретраи
└── .env              # Ваши секреты (не попадает в git)
```

## Запуск

```bash
npm install
cp .env.example .env    # и впишите свой ключ
npm start               # http://localhost:3456
```

Для разработки с перезапуском при изменениях в `server/`:

```bash
npm run dev
```

Без `OPENAI_API_KEY` сервер поднимется, но бот будет отвечать заготовкой — удобно,
чтобы не тратить лимиты на отладке вёрстки.

### Переменные окружения

| Переменная       | По умолчанию  | Назначение                                   |
| ---------------- | ------------- | -------------------------------------------- |
| `OPENAI_API_KEY` | —             | Ключ OpenAI. Без него ИИ отключён.            |
| `OPENAI_MODEL`   | `gpt-4o-mini` | Модель chat.completions.                      |
| `PORT`           | `3456`        | Порт HTTP.                                    |
| `MAX_MESSAGES`   | `20`          | Размер контекстного окна (реплик).            |
| `RPS_LIMIT`      | `20`          | Запросов к `/api/chat` с одного IP в минуту.  |

## Как это работает

1. Браузер собирает историю реплик и шлёт `POST /api/chat` с телом
   `{ "messages": [{ "role": "user", "content": "..." }, …] }`.
2. Сервер срезает окно до `MAX_MESSAGES`, подмешивает system prompt из
   `server/context.js` и спрашивает модель.
3. Ключ OpenAI живёт только на сервере — в браузер он не попадает и в коде
   фронтенда не встречается.

### Поведение вне темы

`context.js` диктует модели правило: на вопрос не про кофейню отвечать служебной
меткой `[[OUT_OF_SCOPE]]`. Сервер её вылавливает и подменяет ответ дефолтным —
так клиент не видит противного «я не могу помочь с этим» и получает одинаковую
реакцию на бессмысленные вопросы.

Менять ассортимент, цены и контакты можно, не трогая код: всё это в
`server/context.js`, он целиком уходит в system prompt.

## API

`GET /api/health` — статус и признак включённого ИИ.

```json
{ "ok": true, "model": "gpt-4o-mini", "aiEnabled": true }
```

`POST /api/chat`

```json
{ "messages": [ { "role": "user", "content": "цена капучино?" } ] }
```

```json
{ "reply": "Капучино — 650 ₸ …" }
```

Ошибки: `400` при пустом теле, `429` при превышении лимита, `502` при неверном
ключе. Таймауты и сетевые сбои OpenAI деградируют в `200` с
`{ "reply": …, "degraded": true }`, чтобы чат никогда не падал.

## Про ИИ и контекст

Виджет хранит историю в `sessionStorage`, поэтому перезагрузка страницы не
сбрасывает диалог; кнопка «очистить» в шапке виджета сбрасывает её.
